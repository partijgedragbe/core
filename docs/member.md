# members

## Overview page

There is an overview page that shows the current members:

`https://www.dekamer.be/kvvcr/showpage.cfm?section=/depute&language=nl&cfm=/site/wwwcfm/depute/cvlist54.cfm` 

And then overview pages for each sessions

`https://www.dekamer.be/kvvcr/showpage.cfm?section=/depute&language=nl&cfm=cvlist54.cfm?legis=56&today=n`

Where `legis=56` is used to set the session.

## Detail pages

The detail page:

`https://www.dekamer.be/kvvcr/showpage.cfm?section=/depute&language=nl&cfm=cvview54.cfm?key=07757&lactivity=56`

**Member ID**

Where `key=07757` shows the unique ID of the member. This ID is unique to each member and stays the same for a member throughout all of their active sessions.

**NOTE: **
Some members have an ID that starts with an 'O' instead of a '0'. This is likely an error from De Kamer.
